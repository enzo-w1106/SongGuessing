# 🏕️ 營火盲盒猜歌王 (Campfire Blind Song Quiz)

> 專為露營聚會設計！徹底解決「遊戲製作者／出題者因為看過題目不能一起玩」的遺憾，全員 100% 盲玩不劇透、支援朋友手機私下秘密投稿與三階段語音搶答。

---

## 🌟 核心特色

1. **製作者 100% 盲玩不破梗**：
   - **主題隨機盲抽模式**：內建「🔥 90-00 華語金曲」、「👑 周杰倫經典專場」、「🎸 五月天派對大合唱」、「🏕️ 台灣獨立樂團露營夜」、「✨ 經典動漫神曲」、「🕺 歐美流行告示牌」。後端隨機暗抽曲目並打亂順序，房主螢幕也看不到歌名與封面。
   - **朋友私下投稿大亂鬥**：每位朋友用手機秘密搜尋並投稿 2～5 首自己的私藏愛歌，系統全自動混洗，播到時才揭曉「這首是誰投的！」。
2. **黑膠盲盒播放器 (Blind Vinyl Mode)**：
   - 房主的手機可以一邊接藍牙喇叭放歌、一邊當作自己的搶答鈴。揭曉前連房主都不知道播的是哪首。
3. **三階段刺激搶答 ＋ 無裁判防劇透判定**：
   - **Stage 1（前奏 1.2 秒挑戰，+300 分）** ➔ **Stage 2（進階 3.5 秒挑戰，+200 分）** ➔ **Stage 3（全體四選一競速，+100~150 分）**。
   - **防劇透驗證**：搶到鈴的玩家可透過 **🎤 手機麥克風大聲喊出歌名（自動語音轉文字模糊比對）** 或 **🎯 8 選 1 快篩候選面板**。
   - **答錯不洩題**：若答錯僅扣 30 分且正解繼續保密，自動推進至下一階段讓其他人繼續猜！
4. **免音檔依賴與露營抗斷線快取**：
   - 內建高音質試聽串流代理與自動預載快取，不怕露營區網路波動。
   - 遊戲音效（搶答鈴、答對、答錯、滴答聲）皆由 Web Audio API 即時物理合成，零載入延遲。

## 🚀 啟動與遊玩方式

### 方式一：在電腦上點擊啟動（在家玩 / 帶筆電去露營）
1. 在資料夾內對著 **`【一鍵啟動遊戲】.bat`** 點擊兩下。
2. 系統會自動啟動並打開瀏覽器，終端機與畫面上會顯示 **QR Code**。
3. 同 Wi-Fi 下的朋友（或連同一個手機熱點的朋友）**拿起手機相機掃描 QR Code** 即可立即加入房間！

---

### 方式二：露營現場完全不帶電腦（100% 只用手機開玩）
若去露營時不想帶筆電，可將本專案部署至任何支援 Node.js 的免費雲端平台（例如 **Render** 或 **Railway**）：
1. 將本專案上傳至您的 GitHub 倉庫。
2. 在 [Render.com](https://render.com) 點選 **New Web Service**，連結該 GitHub 倉庫。
3. 設定：
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. 部署完成後，您會獲得一個專屬的永久 HTTPS 網址（例如 `https://campfire-quiz.onrender.com`）。
5. 露營時：
   - **您的手機** 開啟網址，點「建立新房間」並連上藍牙喇叭。
   - **朋友們** 掃描您手機螢幕上的 QR Code，大家就能坐在營火旁用各自的手機刺激搶答！
